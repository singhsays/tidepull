tidepull

tidepull keeps local directories in sync with cloud storage. It is a pull-only sync daemon for headless servers and homelabs: it watches your cloud storage accounts and mirrors changes to local folders on a fixed interval.

Features

  • One-way pull: the cloud copy always wins, the local tree is a mirror.
  • Multiple accounts, each with its own remote folder, local directory, and interval.
  • Google Drive and Dropbox support.
  • Optional archive of locally deleted files instead of hard deletes.
  • Status page with account authorization, for headless machines.
